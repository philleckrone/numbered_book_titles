Numbered Book Titles is a Paratext tool that checks that the numbered books, 1 Samuel to 3 John, write their number the same way in the running header, the table of contents lines, the main titles and the book names. For each field, the way most books write the number is the usual one, and the books that write it differently are listed with a suggested change. It changes the lines you tick, after adding a point to the project history and keeping a backup of each changed book.
